# Estudo de Listas em HTML

Projeto pra aprender os tipos de lista em HTML.

## Conceitos estudados

- **Lista ordenada** — `<ol>` com itens numerados
- **Lista não ordenada** — `<ul>` com marcadores
- **Lista aninhada** — listas dentro de listas
